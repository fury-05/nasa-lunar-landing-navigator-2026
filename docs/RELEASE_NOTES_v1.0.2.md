# Release notes: v1.0.2

Released 2026-11-15. Patch release on top of v1.0.1. The engine, the API contract and the numbers are unchanged. **Planning tool, not for flight operations.**

## What changed since v1.0.1
* **Credits page:** the "terms confirmed / not yet confirmed" labels and the "pending-source" credit line are removed from the cards. Names, publishers, credit lines and links stay (PR 208). The registry in `data/attribution.json` and `docs/ATTRIBUTION.md` is unchanged.
* **README:** the contributors badge shows 4, the limitations are a short "Scope and limitations" section, and the credit-rules paragraph is removed from the Team section (PR 208).
* **Presentation deck:** the 7-slide deck (pptx, PDF and the build script) is now in `docs/presentation/`.

## Unchanged
The limits in [RELEASE_NOTES_v1.0.0.md](RELEASE_NOTES_v1.0.0.md) still apply, including that results are upper bounds while terrain is incomplete.
